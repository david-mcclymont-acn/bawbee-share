# A Wee Bawbee

Our household finance app: budgets, what-ifs, payday transfers, bank sync, childcare and mortgage.

Start with [PLAN.md](PLAN.md). The people are Person 1 and Person 2, and everything in `seed/` and `reference/` is made-up example data in the original spreadsheet's format, so the golden and parity tests run on it. Put your own figures in your own private copy, never in a public one.
